# 敌人指南针提示开发与验证

## 改动

- 将指南针扫描从侧边栏任务移至独立的比赛任务，保留普通模式 60 秒、猎人模式 1 秒扫描周期；首次立即扫描。
- 原版快捷栏上方提示八方向、约略水平距离、定位年龄。主副手持普通指南针显示，磁石指南针不接管。
- 每个玩家独立选择最近敌人，按原有三维距离比较，增加同维度、有效参战身份检查。方向和距离均以旧定位快照计算，直到下一次扫描。
- 失效目标、退出/结束比赛清理定位和提示。主世界以外明确说明普通指南针限制。
- 操作与限制见 [功能说明](../../enemy-compass.md)。

## 验证结果（2026-09-18）

- Java 21 `gradlew --offline --no-daemon --console=plain build` 通过。
- `python tests/run_all.py` 全部 7 组通过，包含直接编译生产算法的 57 项指南针几何检查。
- 更新后的 Fabric 1.21.1 开发服务端启动成功，用四个 Mineflayer 1.21.1 协议客户端、红蓝各两人开局，检查实际下发的指南针位置包与提示文本，12 项通过：
  1. 排除 2 格外的队友，选择右前方约 120 格的敌人，而不是 200 格外敌人。
  2. 敌人移动后，下一次扫描前保持旧定位点及其距离。
  3. 持有者转身后，方向更新为左前方。
  4. 收起指南针清除提示。
  5. 副手持指南针使用同一定位。
  6. 磁石指南针不显示敌人提示。
  7. 目标变为旁观者时清除定位及指向。
  8. 下一轮扫描改选剩余敌人，继续排除队友和旁观者。
  9. 目标跨维度时立即作废旧定位。
  10. 下一轮扫描显示同维度暂无敌人。
  11. 持有者进入下界时显示普通指南针限制。
  12. 对局结束清除所有持有者的提示。
- `git diff --check` 通过。

多人测试通过的是实际服务器协议行为；没有声称已由真人原版客户端完成字体、布局的视觉验收。猎人模式这一轮未单独开局实测。

## 配置开关与定位间隔（同日追加）

- 配置书第 1 页从 6 项增至 8 项，逻辑页数仍为 5，第一页仍为单个物理书页（导航、标题、8 行设置）。
- `enemyCompass=true` 为总开关，控制所有模式的定位和提示；关闭后清理状态并恢复普通指向。
- `compassInterval=0` 默认自动，保持普通模式 60 秒、猎人/幽灵猎人 1 秒；1～300 为自定义游戏秒，按钮步长 5，可直接输入 1。
- 对局中修改在下次任务更新（最迟 5 tick）生效；重新开启或有效间隔改变立即扫描。显示箭头更新仍为每 5 tick。
- 配置文件保留整数值，书中显示“自动”或“数字秒”；预设与玩法重置沿用现有配置体系。
- 7 组快速检查和最终 Java 21 构建通过。独立临时服务端的 32 项检查覆盖默认值、边界验证、页数和行数、预设持久化、主开关清空状态及实际重置/清空提示包、重新开启、自定义间隔和两种猎人模式。网络输出由测试处理器捕获；不是此次又进行了真人视觉验收。
- 验证环境为 `run/compass-config-smoke/`，绑定本机 25568，使用独立世界、关闭预生成，结束后自动退出；测试代码未打入正式 JAR。原服务器及原世界保持关闭、未启动。
