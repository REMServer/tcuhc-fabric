## 最终改动

### 1. NBT 大厅及生命周期

- `SpawnPlatform` 加载 `tcuhc:lobby/iceland`，按模板尺寸计算放置和清理范围，替换七个硬编码平台及矩形屏障。
- 收录玩家装修后的 `iceland.nbt`：51 × 60 × 47，包含完整空气区域，以保留拆除效果；25 个方块实体、6 个装饰盔甲架。
- 保留 `pyramid.nbt` 作为早期示例；默认模板及三个落点仍由 Java 常量指定，没有新增大厅选择命令或配置项。
- 加入、复活和返回大厅使用经过地板及头部净空验证的三个落点；跨维度返回明确传送到主世界。
- 赛后先重建大厅，再传送玩家；开局清理完整模板范围和带标签的装饰，容器内容不会散落到比赛世界。
- 装饰使用每次放置独有的标签，异步载入的旧盔甲架会延迟清理，避免重启后重复。
- `LobbyBlockTicksMixin` 暂停活跃大厅范围内的方块随机刻及计划刻；`LobbyInteractionMixin` 阻止非创造玩家破坏或使用大厅方块。两个 Mixin 已登记。
- 创造模式可装修；普通玩家离开大厅范围或跌落时会返回。配置书仍可对空气使用。
- 修复 `UhcWorldData` 构造时写回默认值的问题，避免 Gson 读取存档时覆盖已有数据及导致大厅高度漂移。

Iceland 来自用户提供的 `Hub - Iceland.zip`，原包 README 指向作者 LukyTechnology；本次未将该建筑声明为原创。WorldEdit 只用于一次性旧 schematic 转换，不是部署依赖。来源及转换细节见大厅文档。

### 2. 侧边栏

- 标题改为“对局信息”；标签保持白色，数值显式保持原版红色，不增加模式或品牌行。
- 剩余时间、地狱关闭、洞穴关闭显示为“几分几秒”；底层整数秒数继续供玩法逻辑读取。
- 新增存活人数及存活队伍比例，分母固定为本局初始参赛人数及非空队伍数；旁观者和空队排除，断线不视为死亡。
- 后期四行坐标合并为“安全高度范围”和“边界中心”，沿用原有边界计算。
- 开新局清理旧条目；停止的任务不再更新计分板。文本未变但旧颜色不同也会刷新。
- 通过 1.21.1 原生 `FixedNumberFormat` 显示文本，不需要客户端扩展。

### 3. 奖励箱附魔书

- 从三个随机池中移除效率；耐久原本已不在池中，继续排除。
- 将书从顺序珍贵物品池中分离，每个非空奖励箱独立抽取一次，最多一本。
- 普通和 ICARUS 出书率 4/64（6.25%）；MARINE 额外各有 1/64 的引雷 I、激流 I，合计 6/64（9.375%）。这会提高出书率，是有意的奖励平衡调整。
- 书只放入空槽位，不覆盖其他奖励；可以与先抽中的钻石或工具共存。移除旧池中的书也使后续非书奖励不再被书阻挡。
- 随机等级仍按 75% I、25% II 抽取，再限制到附魔的合法范围，例如水下速掘最高为 I。
- 保留原有延迟放置及种子随机数机制，不在区块生成线程写方块实体。

## 使用与维护

- 更新代码或打包内的大厅模板后，需要重启服务端。仅调整大厅和侧边栏无需重生成比赛地图。
- 游戏内装修不会自动回写项目 NBT，仍需再次导出；本次没有添加告示牌指令绑定。
- 奖励规则只影响新版代码填充的奖励箱，已有箱子和玩家物品不重抽。村民交易、附魔台及其他结构战利品不在本次调整范围内。
- 没有新增命令或配置项，因此本次不改双语命令目录；后续若增加命令，应同步维护该目录。
- 根 README 维护功能概览与文档入口；长期行为规则更新对应专题文档，每次开发的验证证据留在日期目录中。
- 模组版本仍为 1.2.9；本次代码提交不等于发布新版本，也不会更新已有 Release JAR。
