# Iceland 出生大厅（Minecraft 1.21.1）

Iceland 大厅使用 `tcuhc:lobby/iceland`，资源文件是
`src/main/resources/data/tcuhc/structure/lobby/iceland.nbt`。
客户端仍可使用原版 Minecraft 1.21.1，无需安装 WorldEdit 或客户端模组。

现在确认执行 `/uhc regen` 会按四图顺序轮换大厅，普通重启和赛后返回保留当前大厅；见 [大厅轮换说明](lobby-rotation.md)。下文介绍 Iceland 模板本身。

## 来源与转换

- 来源：用户提供的 `Hub - Iceland.zip` 中的 `Iceland.schematic`。
- 原包 README 将作者资料指向 LukyTechnology，地图标注适用 1.8+。
- 模板尺寸：51 × 60 × 47（X、Y、Z）；13,907 个非空气方块。
- 使用 WorldEdit Fabric 7.3.8 的旧 schematic 兼容层转换方块及方块实体。
- 6 个盔甲架通过 Minecraft 原版 DataFixer 从旧实体格式升级到 1.21.1，
  保留姿势、装备及头颅纹理，移除固定 UUID，并加上 `tcuhc_lobby` 标签。
- 转换后的 57 个方块实体保留告示牌、头颅、旗帜、容器等数据；旧花盆转换为现代方块状态。
- 盔甲架设置无重力、无敌及装备锁定。WorldEdit 只用于一次性转换，不是运行依赖。

## 大厅行为

模板水平居中放在主世界，底部高度沿用世界 `uhc.json` 的 `spawnPlatformHeight`。
中央路径的地板在模板相对 Y=29，三个落点为 (24,29,23)、(26,29,23)、(28,29,23)。
模板底部 Y=160 时，玩家脚部在 Y=190.1。

- 加入、复活及赛后返回使用中央路径落点，头顶两格净空会在放置时验证。
- 大厅不生成额外矩形屏障地板，保留浮岛的外形。
- 非创造、非旁观玩家跌落到中央地面下方 12 格，或离开大厅水平边界，会被传送回来。
- 活跃大厅范围内暂停方块随机刻和计划刻，保留冰雪、树叶、装饰火焰及水体；
  不修改全局随机刻规则，不影响大厅之外的比赛地图或其他维度。
- 活跃大厅内阻止非创造玩家破坏和使用方块；配置书在空气中使用不受此限制。
  创造模式仍可编辑建筑。
- 开局清理完整模板范围和带有大厅标签的装饰实体；重建前也清理旧装饰，避免重启或
  赛后返回时重复生成。赛后先放置大厅，再传送玩家。
- 每次放置还会为装饰分配本次生成标签；实体区块异步加载时清理旧标签，
  解决重启后旧盔甲架晚于模板加载而重复出现的问题。

`UhcWorldData` 的构造器不再保存默认值，避免 Gson 读取存档时先覆盖文件，
进而使平台高度丢失并在下一次启动中因采样旧大厅而升高。
