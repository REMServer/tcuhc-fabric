# 对局右侧信息

右侧标题为“对局信息”，不增加模式或品牌展示。边界半径及比赛计时规则保持不变。

沿用原版侧边栏的颜色：标题和条目名称保持白色，右侧数值保持红色。分钟秒数、存活比例和合并后的边界信息也显式使用原来的红色；刷新时同时比较文字和样式，修正旧的白色格式。

## 时间显示

剩余时间、地狱关闭和洞穴关闭倒计时统一显示为“几分几秒”，例如 `90分0秒`、`1分5秒`、`0分59秒`。超过一小时仍累计显示分钟。归零或超时后的可见值最低为 `0分0秒`。

显示使用原生 FixedNumberFormat；计分板底层仍保存原来的整数秒数，缩圈、关闭区域及胜负判断读取的时间不变。

## 存活统计

- `存活人数：8 / 12`：当前存活参赛人数 / 本局初始参赛人数。
- `存活队伍：3 / 4`：仍有存活成员的队伍数 / 本局初始非空队伍数。
- 旁观者和配置出来的空队伍不计入分母；断线不视为死亡。
- 玩家恢复存活状态后重新计入人数，其队伍也可重新计入存活队伍。
- 每 20 tick 更新，下一局重新取得参赛名单及分母。

## 后期边界信息

洞穴关闭后的原四行坐标合并为两行，沿用实际边界逻辑计算出的值：

```text
安全高度范围：64～90
边界中心：X 120，Z -80
```

高度下限向上取整、上限向下取整，中心保留 X、Z 轴标记和负号。开新局清理上局的后期条目，以及旧版本遗留的四行坐标。

新增条目使用 Minecraft 1.21.1 原生 FixedNumberFormat 显示文本，客户端无需模组。它们使用独立排序值；原倒计时分数仍供比赛逻辑读取。内容未变化时复用原有格式，避免重复发送文本更新。

## 验证

2026-09-16 在独立 Fabric 1.21.1 专用测试服中通过 40 项断言，覆盖旁观和空队排除、离线参赛者、死亡和全队出局、恢复存活状态、实际洞穴任务产生的边界信息、计时不受影响、停赛及下一局清理。验证使用模拟参赛记录，未替代真实多客户端的视觉验收。

随后增加分钟秒数显示检查，共 74 项断言通过；额外覆盖 0、1、59、60、61、3600、5400 秒、关闭倒计时归零、超时显示及下一局首次显示，确认底层规则时间不受文本格式影响。

本地验证入口及日志在忽略目录 `run/sidebar-smoke/`，临时测试类不加入发布构建。

恢复原版红色数值后，共 104 项断言通过；新增检查覆盖所有自定义数值的红色样式，以及文字未变化但旧样式为白色时仍能正确更新。
